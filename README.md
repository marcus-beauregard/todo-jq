# todo-jq

[![CI](https://github.com/marcus-beauregard/todo-jq/actions/workflows/ci.yml/badge.svg)](https://github.com/marcus-beauregard/todo-jq/actions/workflows/ci.yml) [![License: GPL-2.0-or-later](https://img.shields.io/badge/license-GPL--2.0--or--later-blue.svg)](LICENSE)

A tiny todo app built with jQuery and localStorage. No build step, no framework —
just open index.html and go. My first "ship it and forget it" project.

Features: add/complete/delete tasks, persistent via localStorage, clear-completed.

## Contributing

Humans and automated agents are both welcome. There is no CLA — every commit carries a [DCO](https://developercertificate.org/) sign-off (**git commit -s**). Start with a [good first issue](https://github.com/marcus-beauregard/todo-jq/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or read [CONTRIBUTING.md](CONTRIBUTING.md).
